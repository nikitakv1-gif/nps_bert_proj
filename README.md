# Проект для Samsung Innovation Campus: Анализ NPS и Эмоций Отзывов

## Обзор

Этот проект был выполнен Багровой Ксенией и Квернадзе Никитой, студентами РТУ МИРЭА, ИТУ, УСБО-01-22, в рамках программы Samsung Innovation Campus.

Основной задачей данного проекта было создание и обучение модели, способной предсказывать NPS (Net Promoter Score) отзыва и рассчитывать общий NPS по пакету отзывов.

Проект представляет собой веб-приложение на Flask, которое позволяет загружать Excel-файлы с отзывами или вводить отзывы вручную, а затем использует модели машинного обучения для предсказания Net Promoter Score (NPS) и анализа эмоциональной окраски текста. Результаты визуализируются и могут быть сохранены.

Ноутбук с кодом обучения модели находится в `model/presave/review-classigfication.ipynb`, а также доступен на Kaggle.

## Функциональность

*   **Загрузка и обработка отзывов из Excel-файлов:**
    *   Приложение принимает Excel-файлы (форматы .xlsx, .xls) с отзывами.
    *   Автоматическая обработка и извлечение данных из указанных колонок (`text`, `plus`, `minus`).
*   **Предсказание NPS:**
    *   Использование обученной модели машинного обучения для расчета NPS на основе предоставленных отзывов (текст, плюсы, минусы).
*   **Анализ эмоциональной окраски:**
    *   Определение эмоционального тона отзывов с помощью отдельной модели анализа эмоций.
*   **Веб-интерфейс:**
    *   Удобный интерфейс для загрузки файлов или ввода текста вручную.
    *   Отображение результатов предсказания NPS и интерактивных графиков (на базе Plotly).
    *   Возможность отправки пользовательского NPS для сохранения в базе данных.
    *   Предварительный просмотр загружаемых Excel-файлов.
    *   Скачивание обработанных данных в формате Excel.
*   **Хранение данных:**
    *   Использование базы данных SQLite для сохранения пользовательских оценок NPS.

## Краткое описание работы алгоритма

В связи с тем, что размеченных данных по NPS оценкам найдено не было, использовался расчетный метод оценки NPS для каждого отзыва.

### 1. Этап: Оценка звездности отзыва

Для обучения использовали отзывы, состоящие из трех частей: общий текст, плюсы и минусы. Для анализа каждой части использовался трансформер `rubert-tiny2`. В итоге три трансформера с общей памятью исследовали каждую часть отзыва, и на основе их оценок использовалась линейка, выдающая итоговый результат.

### 2. Этап: Оценка эмоциональности отзыва

Задача данной модели — оценить, насколько отзыв положительный, чтобы точнее оценивать NPS скор отзыва в последствии. В данном случае использовалась предобученная модель `"blanchefort/rubert-base-cased-sentiment"`, без каких-либо изменений и дообучений.

### 3. Этап: Оценка NPS

После первого этапа, для каждого отзыва сохраняется предсказанная звездность от 1 до 5. После второго этапа сохраняются вероятности после softmax преобразования.

Перед расчетом итоговой оценки NPS, оценки переводятся в шкалу от 0 до 1 по следующей формуле:

$$
star_{new} = \frac{(star - 1)}{4}
$$

А на основе результатов модели по эмоциям рассчитывается средняя метрика по формуле:

$$
avg_{emo} = emo_{positive} - emo_{negative} + 0.5 \cdot emo_{neutral}
$$

Итоговая формула для расчета NPS оценки:

$$
nps_{score} = star_{new} \cdot avg_{emo} \cdot 10
$$

## Установка

Для запуска проекта на вашей локальной машине выполните следующие шаги:

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/your-username/your-repository-name.git
    cd your-repository-name
    ```
    (Замените `your-username/your-repository-name.git` на актуальный адрес репозитория)

2.  **Создайте и активируйте виртуальное окружение (рекомендуется):**
    ```bash
    python -m venv venv
    # Для Windows
    venv\Scripts\activate
    # Для macOS/Linux
    source venv/bin/activate
    ```

3.  **Установите зависимости:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Скачайте ChromeDriver:**
    Если вы планируете использовать парсеры в директории `parsers/`, вам может потребоваться [ChromeDriver](https://googlechromelabs.github.io/chrome-for-testing/); убедитесь, что его версия соответствует версии вашего Google Chrome. Поместите `chromedriver.exe` в корень проекта или убедитесь, что он находится в PATH.

## Использование

1.  **Запуск приложения:**
    ```bash
    python main.py
    ```
    Приложение будет доступно по адресу `http://127.0.0.1:5000/` (или другому порту, если указано в `main.py`).

2.  **Работа с веб-интерфейсом:**
    *   Откройте веб-браузер и перейдите по указанному адресу.
    *   Вы можете выбрать между загрузкой Excel-файла или вводом текста отзыва вручную.
    *   **Для Excel-файла:**
        *   Нажмите "Выберите файл" и выберите ваш файл.
        *   Убедитесь, что ваш Excel-файл содержит колонки с названиями `text`, `plus` и `minus`.
        *   Нажмите "Загрузить и Анализировать".
    *   **Для ручного ввода:**
        *   Введите текст отзыва, его плюсы и минусы в соответствующие поля.
        *   Нажмите "Анализировать".

3.  **Результаты:**
    *   После обработки на странице отобразится предсказанный NPS и график распределения оценок.
    *   Вы можете ввести свою оценку NPS в соответствующее поле и нажать "Отправить оценку", чтобы сохранить ее в базе данных.
    *   Если был загружен Excel-файл, будет доступна кнопка для скачивания обработанного файла.

## Структура проекта

*   `app/`: Основное Flask-приложение.
    *   `__init__.py`: Инициализация приложения.
    *   `routes.py`: Определяет маршруты и логику обработки запросов.
    *   `templates/`: HTML-шаблоны для веб-интерфейса.
    *   `unpack.py`: Функции для распаковки данных из Excel-файлов.
*   `database/`: Модули для работы с базой данных (SQLite).
    *   `db.py`: Логика взаимодействия с базой данных.
*   `excelworker/`: Модули для работы с Excel-файлами.
    *   `userexcel.py`: Утилиты для работы с пользовательскими Excel-данными.
*   `model/`: Содержит файлы, связанные с моделью машинного обучения.
    *   `dataset.py`: Работа с наборами данных.
    *   `evaluate.py`: Скрипты для оценки модели.
    *   `predict.py`: Логика предсказания с использованием обученных моделей.
    *   `presave/`: Сохраненные веса моделей, файлы токенизаторов и ноутбук с обучением модели (`review-classigfication.ipynb`).
    *   `quantilization.py`: Возможно, для квантизации моделей.
    *   `ThreeInputModel.py`: Определение архитектуры модели.
*   `parsers/`: Скрипты для парсинга данных с различных веб-сайтов (Otzovik, Irecommend, WB).
    *   `otzovik_parser.py`, `Ireccomend.py`, `wb.py`: Примеры парсеров.
*   `uploads/`: Директория для временного хранения загруженных файлов.
*   `main.py`: Точка входа в приложение.
*   `requirements.txt`: Список всех зависимостей проекта.
*   `Procfile`: Конфигурация для деплоя на платформы типа Heroku.
*   `reviews_nps.sqlite`, `your_db.sqlite`: Файлы баз данных SQLite.
